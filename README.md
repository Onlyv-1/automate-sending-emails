# automate-sending-emails
A Python-based tool that automatically sends emails at scheduled times. It allows users to input their email credentials, recipient address, subject, and message, then uses SMTP and the schedule library to deliver emails at set intervals (hourly, daily, etc.).

## Status
This project is First release.

## Features
- auto sending emails

- repating the email at set intervals.
